# Distribution of Electric Vehicle Range

plt.figure(figsize=(10,5))
sns.histplot(df["Electric Range"], kde=True)
plt.title("Distribution of Electric Range")
plt.show()

During analysis of this visualization, records were found to contain electric vehicles with a range of zero. Because no BEV or PHEV has an eletric only range of zero miles, these entries represent either missing data, data entry error, or data not relevant to this analysis. The presence of this data creates a clear distortion in the distribution of the electric range and artificially inflates the density seen at the lower end of the visualization. This results in obscuring the separation between PHEVs and BEVs. In an attempt to preserve accuracy and prevent erroneous values from influencing regression, classificaiton and clustering results, all zero-range records will be removed before modeling. This ensures that the analysis reflects realistic vehicle characteristics and maintains the conciseness and jargon free nature of this analysis.

# MSRP vs. Electric Range

plt.figure(figsize=(10,5))
sns.scatterplot(data=df, x="Electric Range", y="Base MSRP", hue="Electric Vehicle Type")
plt.title("Range vs. MSRP")
plt.show()

In the Range vs. MSRP scatterplot, the presence of vehicle record 68089 in the dataset, with an MSRP exceeding $800,000.00, is seen and creates a large vertical stretch in the plot. Because there are no other vehicles in the dataset that exceed $200,000.00, this single value compresses the rest of the points into a narrow band. The result is a visualization that hides meaningful structure, obscures BEV/PHEV separation, and makes the relationship between range and price appear much flatter and noisier than it truly is.

We can remove this value because it isn't representative of the EV market as a whole; it's a Porsche 918. This value harms the analysis by distorting the visualization, will lead to inflating regression error, disrupting scaling, and will reduce the interpretability of future models.

# Regression Modeling to Predict MSRP
##############################

# Define the feature matrix, X, and target vector, y, utilizing the cleaned dataset

X_reg = df_clean[["Model Year", "Electric Range", "Make", "Model", "County", "City"]]
y_reg = df_clean["Base MSRP"]

# Features to be one-hot encoded

numeric_features = ["Model Year", "Electric Range"]
categorical_features = ["Make", "Model", "County", "City"]

# Preprocessing pipeline with StandardScaler for numeric variables and one-hot encodes categorical features

preprocess_reg = ColumnTransformer(
    transformers=[
        ("num", StandardScaler(), numeric_features),
        ("cat", OneHotEncoder(handle_unknown="ignore"), categorical_features)
    ]
)

# Pipeline continues, preprocess data, fit linear regression model to ensure preprocessing is applied consistently

reg_model = Pipeline(steps=[
    ("preprocess", preprocess_reg),
    ("model", LinearRegression())
])

# 80 / 20 train/test split with random_state for reproducability

X_train, X_test, y_train, y_test = train_test_split(X_reg, y_reg, test_size=0.2, random_state=50)

reg_model.fit(X_train, y_train)
y_pred = reg_model.predict(X_test)

print("R² Score:", r2_score(y_test, y_pred))
print("RMSE:", np.sqrt(mean_squared_error(y_test, y_pred)))

# Classification Model to Predict Battery Electric Vehicle vs Plugin Hybrid Electric Vehicle
##############################

# Define feature matrix, X, and target vector, y, using the cleaned dataset

X_clf = df_clean[["Model Year", "Electric Range", "Make", "Model", "County", "City"]]
y_clf = df_clean["Electric Vehicle Type"]

# Preprocessing pipeline for classification, standardizes numeric features, and one-hot encodes categorical features

preprocess_clf = ColumnTransformer(
    transformers=[
        ("num", StandardScaler(), numeric_features),
        ("cat", OneHotEncoder(handle_unknown="ignore"), categorical_features)
    ]
)

# Classification pipeline, apply preprocessing, train a Random Forest classifier where n_estimators=200 for a stable 
# ensemble and random_state for reproducability

clf_model = Pipeline(steps=[
    ("preprocess", preprocess_clf),
    ("model", RandomForestClassifier(n_estimators=200, random_state=50))
])

# 80 / 20 train/test split with random_state for reproducability

X_train_c, X_test_c, y_train_c, y_test_c = train_test_split(X_clf, y_clf, test_size=0.2, random_state=50)

clf_model.fit(X_train_c, y_train_c)
y_pred_c = clf_model.predict(X_test_c)

print(classification_report(y_test_c, y_pred_c))
